# مرکز توانمندسازی معلمان شمس (Shams Teacher Empowerment Center)

وب‌سایت رسمی و تک‌صفحه‌ای «مرکز توانمندسازی معلمان شمس» (طرح پیشنهادی برای وزارت معارف افغانستان).

---

## ۱. نحوه ویرایش معلومات کاری (Business Configuration)

تمامی معلومات قابل تغییر مرکز در فایل **`src/config.ts`** قرار دارند:
- **نام و برند:** نام رسمی و مخفف
- **شماره تماس و واتساپ:** شماره تلفن مستقیم افغانستان در فایل `src/config.ts`
- **آدرس و موقعیت:** کابل، افغانستان
- **ساعات کاری:** روزهای هفته و ساعات پذیرش
- **بازه زمانی نوبت‌ها:** ساعت آغاز، پایان و گام‌های زمانی (پیش‌فرض ۰۹:۰۰ الی ۱۵:۳۰ با فواصل ۳۰ دقیقه‌ای)
- **معلومات تیم و ترینرها:** اسامی، القاب، خلاصه تجارب و نشان‌ها
- **رمز پنل مدیریت محلی:** پیش‌فرض `shams1405` (قابل تغییر)

## ۲. اتصال اختیاری به گوگل شیتس (Google Sheets Backend)

سیستم ثبت وقت به صورت پیش‌فرض تمام درخواست‌ها را در حافظه محلی مرورگر کاربر ذخیره می‌کند و پیام تکمیل‌شده را مستقیماً از طریق واتساپ و فایل تقویم (`.ics`) به دست شما می‌رساند.

برای ذخیره همزمان تمام درخواست‌ها در یک فایل اکسل گوگل (Google Sheet)، مراحل زیر را دنبال کنید:

1. یک فایل جدید در [Google Sheets](https://sheets.new) ایجاد کنید.
2. از منوی بالای صفحه به بخش **Extensions** -> **Apps Script** بروید.
3. کد زیر را در ویرایشگر اسکریپت پیست کنید:

```javascript
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var d = JSON.parse(e.postData.contents);
    
    // اگر فایل خالی است، ردیف عنوان اضافه شود
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "زمان ثبت", "کد پیگیری", "خدمت", "گروه هدف", "مکتب", "ولایت",
        "تعداد", "نوعیت", "تاریخ", "ساعت", "شخص رابط", "شماره تماس", "یادداشت"
      ]);
    }
    
    sheet.appendRow([
      new Date(),
      d.code,
      d.service,
      d.audience,
      d.school,
      d.city,
      d.participants,
      d.mode,
      d.dateISO,
      d.time,
      d.name,
      d.phone,
      d.note || ""
    ]);
    
    return ContentService.createTextOutput("ok").setMimeType(ContentService.MimeType.TEXT);
  } catch (err) {
    return ContentService.createTextOutput("error: " + err.message).setMimeType(ContentService.MimeType.TEXT);
  }
}
```

4. روی دکمه **Deploy** -> **New deployment** کلیک کنید.
5. نوع آن را **Web app** انتخاب کنید:
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`
6. روی **Deploy** کلیک کرده و لینک Web App URL تولید شده را کپی کنید.
7. لینک را در فایل `src/config.ts` در متغیر `sheetWebhookUrl` قرار دهید:

```typescript
export const CONFIG = {
  // ...
  sheetWebhookUrl: 'https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec',
  // ...
};
```

## ۳. ویژگی‌های پیاده‌سازی‌شده

- **طراحی کاملاً راست‌به‌چپ (RTL) به زبان دری افغانستان:** استفاده از واژگان اصیل معارف افغانستان (مکتب، صنف، شاگرد، معارف، سرمعلم، ترینر، نیازسنجی، پالیسی، مشوره).
- **اعداد فارسی-عربی (۰۱۲۳۴۵۶۷۸۹):** در تمام بخش‌ها، تقویم و کد‌های پیگیری.
- **تقویم هجری شمسی افغانستان:** نام ماه‌های حمل، ثور، جوزا، سرطان، اسد، سنبله، میزان، عقرب، قوس، جدی، دلو، حوت.
- **سیستم رزرو آنلاین تعاملی (۴ مرحله‌ای):**
  - اعتبارسنجی فرمت شماره موبایل افغانستان (`07...`)
  - غیرفعال‌سازی هوشمند اوقات رزرو شده
  - صدور کد پیگیری اختصاصی
  - دانلود خودکار فایل تقویم استاندارد (`.ics`)
  - اشتراک‌گذاری مستقیم در واتساپ
- **طراحی فاخر، رسمی و دانشگاهی (Institutional & Editorial Architecture):**
  - پالت رنگی رسمی و اداری معتبر: زمینه کاغذ عاجی/آلاباستر گرم (`#FDFCF7` و `#F5F3EC`)، سرمه‌ای درباری عمیق پروس (`#0D1929`) و طلایی-کهربایی خورشیدی باوقار (`#B45309` و `#D97706`).
  - حذف کامل رنگ‌های آبنباتی/پاستلی، پاپ‌آپ‌های انیمیشنی حباب‌دار، کارت‌های شناور حبابی و افکت‌های هوش مصنوعی.
  - ساختار اصیل اسطرلاب و خطوط ظریف هندسی خورشیدی الهام‌گرفته از نشان‌های رسمی علمی.
  - تایپوگرافی اصیل: خط رقعی و نسخ فاخر (Aref Ruqaa) برای سرتیترها و نقل‌قول‌ها، همراه با وزن‌های منظم وزیرمتن برای خوانایی حداکثری.
- **تغییر زبان دوطرفه:** دری (پیش‌فرض) و انگلیسی همراه با تغییر جهت (RTL / LTR).
- **پنل مدیریت داخلی:** امکان ورود با رمز عبور در فوتر سایت، مشاهده تمام درخواست‌ها، تغییر وضعیت (تایید/لغو) و دریافت فایل خروجی CSV (اکسل).
